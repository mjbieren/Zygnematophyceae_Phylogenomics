# Taxon bookkeeping

- `REFERENCE_TAXA_126.txt`: final working list supplied for the repository.
- `Zygnematophyceae_104_working_reference.txt`: first 104 entries of that list. Entry 104 is the oneKP-derived *Spirogloea muscicola* CCAC0214 protein set.
- `OrthoFinder_later_additions_22.txt`: the Cheng-derived *Spirogloea muscicola* CCAC0214 file plus 21 broader reference/outgroup files added for the OrthoFinder stage.

The manuscript reports **104 Zygnematophyceae + 9 other streptophyte algae + 8 land plants + 4 chlorophytes = 125 biological taxa**. The working input-file list has 126 entries because CCAC0214 is represented by two source-specific files. Keep the two source labels distinct when reproducing the working OrthoFinder file set.
