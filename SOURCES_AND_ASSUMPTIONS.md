# Sources and assumptions

This repository was generated from:

1. the supplied `Coleochaetophyceae_Phylogenomics` GitHub ZIP as a structural/code template;
2. the supplied working Zygnematophyceae manuscript; and
3. the 126-entry reference/taxon list supplied during repository preparation.

## Deliberately unresolved items

The working manuscript contains tracked changes and several legacy Coleochaetophyceae phrases in the Methods. In particular, the exact Zygnematophyceae decontamination positive reference, the exact OrthoFinder guide-tree Newick, and final project-specific ACSR input matrices are not unambiguously recoverable from the manuscript. These are left as documented placeholders rather than guessed.

The manuscript describes BUSCO v5.4.3 with `eukaryota_odb10`; those values are retained for reproducibility scripts even though newer BUSCO reruns may use a newer Viridiplantae lineage.
