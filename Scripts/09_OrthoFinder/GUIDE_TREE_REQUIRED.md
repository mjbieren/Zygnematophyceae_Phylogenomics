# Guide tree

The manuscript states that OrthoFinder was run with a species tree following the broad One Thousand Plant Transcriptomes framework, but the exact Newick guide tree is not encoded in the manuscript text.

For strict reproduction, copy the original guide tree from the archived `09_Orthofinder` analysis/Zenodo material and set `TREE_FILE` in `09_Orthofinder.sh`. A fabricated topology is intentionally not supplied here.
