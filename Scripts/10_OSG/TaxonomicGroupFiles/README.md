# Zygnematophyceae taxonomic group files

`Zygnematophyceae_TaxonomicGroupFile_WORKING.txt` groups the 104 working Zygnematophyceae inputs by the five orders recovered in the manuscript: Desmidiales, Spirogyrales, Zygnematales, Serritaeniales, and Spirogloeales.

**Important:** the manuscript's tracked Methods text contains unresolved edits around the exact OSG filter/group counts. Treat this file as transparent working bookkeeping and verify the exact grouping/filter threshold against the archived analysis output before a strict reproduction run.
